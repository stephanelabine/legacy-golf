LEGACY GOLF — TOURNAMENT & PLATFORM BRAIN
Foundational Product Memory & Build Intent

Project name
Legacy Golf

Project start date
December 26, 2025

Primary objective
To build a premium, industry-leading golf platform that removes friction, reduces organizer workload, ensures math integrity, and delivers a calm, beautiful, trustworthy experience for real golfers playing real games with real money.

This is not a hobby app.
This is a commercial, scalable product designed for public App Store release, with private beta use prior to launch.

CORE PRINCIPLES (NON-NEGOTIABLE)

Trust the math
• All calculations must be accurate, explainable, and auditable
• Organizer always has final authority
• Physical course artifacts (placards, scorecards) override app estimates if needed

Reduce organizer workload
• App automates score aggregation, leaderboards, formats, payouts, and status
• Organizer becomes reviewer and adjudicator, not a data clerk
• Organizer isolation after rounds is explicitly a problem this app solves

Calm play, celebratory results
• During play: restrained, focused, low noise
• Results, trophies, payouts: permission to shine, animate, celebrate

One engine, many lenses
• One round engine
• One hole view system
• One score entry system
• Tournament, Normal Play, and Legacy all consume the same core data

Fix once → fixed everywhere
Improve once → improves everywhere

TOURNAMENT LIVE RUNTIME (SUMMARY)

• Organizer starts tournament (single authoritative action)
• Tournament becomes live
• Players see Home callout: “Tournament has begun — start your round. Good luck.”
• Players may start late; each must explicitly start their own round

Player flow:
Home → Assignment screen → Start Round → Hole View → Score Entry → Round Review → Submit

Score entry:
• Default: gross score + putts
• Expandable later if formats require additional stats

Round submission:
• Player locks their round on submit
• Player cannot edit afterward
• Organizer can unlock/edit if needed

FORMAT EVENTS (KP, LONG DRIVE, ETC.)

• Format holes trigger full-screen interstitials before play
• Icons and visuals signal importance without clutter

Long Drive:
• GPS-based pin for UX and visibility
• Physical placard is ultimate authority
• Another player must confirm long drive
• Results are provisional during play
• Organizer can override after the round
• Organizer decision is final

LIVE EXPERIENCE

• Optional in-app “moment bubbles”
– birdies, eagles, leader changes
– rate-limited, non-intrusive
– not push notifications

• In-round leaderboard
– relative to par only (E, +1, -1)
– returns player to exact hole position on exit

END OF ROUND / END OF TOURNAMENT

• Round review scorecard before submission
• End-of-day leaderboard automatically generated
• Formats recap included

Final round:
• Leaders last
• Bottom players go first

Tournament completion:
• Trophy / winner screen
• Payouts summary
• Thank-you message sent to all players

EMAIL & COMMUNICATION SUPPORT

• Optional post-round email summary for players
• Tournament completion thank-you message sent automatically
• Designed to reduce organizer messaging workload

MANUAL COURSE DATA (NO API DEPENDENCY)

Organizer must be able to enter:
• hole numbers
• par per hole
• stroke index (SI)
• tees per round

Required so math works even without third-party APIs.

PLAYER PARTICIPATION MODES

• Self-entered (player uses app)
• Proxy-entered (another player enters scores)
• Organizer-entered (admin inputs later)

No player refusal to use the app should degrade tournament integrity.

FUTURE PILLARS

Normal Play cleanup:
• Match Play explicitly split (1v1, 2v2)
• Games ≠ Wagers (remove redundancy)
• Add games like Birdie Buckets, Nassau, Stableford, Wolff

Legacy Mode:
• Long-term cumulative play across many rounds
• Legacy Card tracks best score per hole over time
• Designed for Men’s Nights, leagues, seasons
• Represents golfer identity, not single-day results

QUALITY BAR

This product must:
• work reliably
• feel premium
• scale cleanly
• be easy to update
• be trusted by organizers and players

There is no settling for “good enough.”
